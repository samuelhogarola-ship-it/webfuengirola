## Copy

Error 1: No decir qué haces en los primeros 3 segundos. Si alguien llega y no entiende tu servicio al instante, se va.

Error 2: Fotos genéricas de stock. Si tu web parece igual que las otras 500, no transmites confianza.

Error 3: No tener un botón de contacto visible en móvil. El 53% abandona si la web tarda más de 3 segundos o no encuentra cómo escribirte.

¿Tu web tiene alguno de estos? Mándanos el enlace y te decimos exactamente qué mejorar.

## Prompt para generar la foto

Composición flat lay de tres pantallas de móvil (mockups) sobre fondo degradado azul oscuro a negro. La primera pantalla muestra una web confusa con texto ilegible y sin jerarquía. La segunda muestra fotos genéricas de stock evidentes. La tercera muestra una web sin botón de contacto visible. Cada pantalla tiene una X roja sutil encima. Estilo infográfico limpio, tipografía sans-serif, paleta azul marino y rojo coral. Formato 1:1, sin texto real legible en las pantallas.
